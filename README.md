## 📖 Project Overview

This project demonstrates the frontend design of a user authentication system. It provides separate interfaces for user login, account registration, and password recovery.

The project is developed for learning and practicing frontend web development concepts using HTML, CSS, and JavaScript.

## ✨ Features

* Login Page
* Signup Page
* Forgot Password Page
* Frontend Form Validation
* Clean User Interface
* Easy Navigation Between Pages
* Beginner-Friendly Project Structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Learning Objectives

* Understand form creation in HTML
* Practice CSS styling and layouts
* Implement JavaScript form validation
* Learn page linking and navigation
* Build a complete frontend authentication flow

## ⚠️ Limitations

* No Backend Integration
* No Database Connectivity
* No User Authentication Storage
* No Email Verification
* No Password Encryption

This project focuses only on frontend development and UI design.
